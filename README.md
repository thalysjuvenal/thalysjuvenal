## 🗺️ Roadmap público

| 🎯 Now (Q2 2026) | 🔜 Next (Q3 2026) | 🔭 Later |
|---|---|---|
| Expansão da base de referência ADVPL/TLPP (mais funções nativas, SX fields, entry points) | Command `/advpl-specialist:probat` — geração de testes ProBat guiada por contrato | Suporte experimental a TOTVS Logix |
| Melhorias no agente `code-generator` para MVC completo com relacionamentos | Integração com VS Code extension / TDS | Documentação e commands em inglês |
| Cobertura de mais módulos Protheus no `process-consultant` | Biblioteca pública de snippets TLPP reutilizáveis | Web playground para testar prompts do plugin |

<sub>O roadmap é indicativo — <a href="https://github.com/thalysjuvenal/advpl-specialist/issues">issues</a> abertas no plugin têm prioridade sobre itens aqui listados.</sub>
